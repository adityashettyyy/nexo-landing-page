# Nexo – Modern Crypto Dashboard Landing Page

A modern, AI-inspired crypto dashboard landing page built using **pure HTML, CSS, and vanilla JavaScript**.  
This project focuses on clean UI design, responsive layouts, and polished interactions without using any frameworks.

🔗 **Live Demo:** https://nexo-landingpage.vercel.app/

---

## ✨ Features

- Modern fintech-style landing page
- Dashboard preview UI
- Responsive design (desktop → mobile)
- Dark theme with gradient accents
- Interactive sidebar & controls
- Clean design system using CSS variables
- No frameworks or libraries used

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **Vercel** (for deployment)

---


## 📱 Responsive Design

- Desktop-first layout
- Optimized for tablets & mobile devices
- Mobile sidebar converts into a horizontal tab bar
- Charts, cards, and grids adapt fluidly

---

## 🎨 Design Highlights

- CSS-only dark theme
- Consistent spacing & typography system
- Smooth hover and focus states
- Subtle glow & gradient effects
- Accessibility-friendly contrasts
